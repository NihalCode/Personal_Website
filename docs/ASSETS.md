# Assets

No photographs, stock renders, or downloaded 3D models are used.

- Room geometry, wood, and plaster are generated in the browser with Three.js.
- The no-WebGL fallback is HTML and CSS in `components/room-poster.tsx`.
- Fonts are `@fontsource/outfit`, `@fontsource/ibm-plex-sans`, and `@fontsource/ibm-plex-mono`. They are bundled with the site. Google Fonts is not called.
- Open Graph image and favicon are generated by Next.js (`app/opengraph-image.tsx`, `app/icon.tsx`).
- The résumé PDF is not in this repository. See `docs/CONTENT_NOTES.md`.
